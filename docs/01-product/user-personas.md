# User Personas — Eventz

**Last Updated:** July 2026

---

## 1. Attendee — "Amina"

**Demographics:** 24, university student in Dar es Salaam, active on social media

**Goals:**
- Discover concerts, meetups, and cultural events
- Buy tickets easily with Mpesa
- Watch live streams when she can't attend in person
- Share event experiences with friends

**Pain Points:**
- Hard to find events outside of word-of-mouth
- Cash-only events mean no refund protection
- Misses events because she didn't hear about them

**Behavior:**
- Browses feed daily for 15-20 minutes
- Follows organizers and friends
- Saves events for later
- Shares events via WhatsApp

**Features Used:** Feed, Events, Tickets, Messaging, Notifications, Live Streaming

---

## 2. Organizer — "David"

**Demographics:** 32, event planner, runs monthly tech meetups

**Goals:**
- Create and manage events professionally
- Sell tickets and track sales
- Build a community around his events
- Go live for remote attendees

**Pain Points:**
- Manual ticket tracking via WhatsApp is error-prone
- No way to reach attendees after the event
- Hard to measure event success

**Behavior:**
- Creates 2-4 events per month
- Checks dashboard daily during event season
- Uses analytics to plan future events
- Engages with attendees via messaging

**Features Used:** Event Creation, Dashboard, Tickets, Analytics, Live Streaming, Messaging

---

## 3. Admin — "Fatuma"

**Demographics:** 28, platform operations manager

**Goals:**
- Keep the platform safe and trustworthy
- Respond to user reports quickly
- Monitor platform health and usage
- Handle payment disputes

**Pain Points:**
- No automated content moderation
- Manual user management is time-consuming
- Hard to track abuse patterns

**Behavior:**
- Reviews reports daily
- Monitors Sentry for errors
- Checks payment transaction logs
- Communicates with users about issues

**Features Used:** Moderation, User Management, Dashboard, Monitoring

---

## 4. Moderator — "John"

**Demographics:** 26, community volunteer, part-time

**Goals:**
- Review reported content
- Maintain community standards
- Help new users get started

**Pain Points:**
- Unclear moderation guidelines
- No tools to batch-process reports
- Hard to distinguish spam from legitimate content

**Behavior:**
- Reviews reports 2-3 times per week
- Flags questionable content
- Escalates complex cases to admin

**Features Used:** Moderation, Reports, User Management

## 5. Sponsor — "Grace" (Planned)

**Goals:**
- Promote brand at relevant events
- Reach target audience through event sponsorship
- Measure ROI on event sponsorships
- Build brand association with exciting events
