# Product Vision — Eventz

**Last Updated:** July 2026

---

## What is Eventz?

Eventz is a mobile-first social events platform built as a Progressive Web App. It combines event discovery, ticket purchasing, live streaming, real-time messaging, and social feeds into a single application optimized for mobile use in East Africa.

## Mission

To become the default platform for discovering, hosting, and experiencing live events in Tanzania and East Africa — powered by mobile money and built for the mobile-first generation.

## Target Market

- **Primary:** Tanzania (nTZS mobile money users — Airtel Money, Mpesa, Mixx/Tigo)
- **Secondary:** East African community events (Kenya, Uganda, Rwanda)
- **Audience:** Urban youth and young professionals (18-35) who attend concerts, conferences, meetups, and cultural events

## Core Value Proposition

| For Attendees | For Organizers |
|---|---|
| Discover events near you | Create and manage events for free |
| Buy tickets with mobile money | Sell tickets and receive payouts |
| Watch live streams from anywhere | Go live and reach remote audiences |
| Chat with friends and organizers | Build community around your events |
| Get notifications for events you love | Track analytics and attendee engagement |

## Long-Term Goals

1. **Scale to 100K+ concurrent users** with proper infrastructure (see `TheArchitecture.md`)
2. **Expand payment methods** beyond nTZS (Stripe, M-Pesa direct, bank transfer)
3. **Launch native apps** (Android/iOS) via Capacitor
4. **Add event analytics** for organizers (views, engagement, demographics)
5. **Build recommendation engine** for personalized event discovery
6. **Enable event sponsorships** and brand partnerships
7. **Multi-language support** (Swahili, English, French)

## Design Principles

1. **Mobile-first** — Every feature designed for thumb-friendly mobile use
2. **Offline-capable** — PWA with service worker for low-connectivity areas
3. **Real-time** — Instant updates for messages, notifications, and live streams
4. **Simple payments** — Mobile money integration for seamless ticket purchases
5. **Social by default** — Every interaction is shareable and connectable
