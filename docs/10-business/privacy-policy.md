# Privacy Policy

**Last Updated**: July 2026

## Introduction

Eventz ("we", "our", "app") is a live events platform that allows users to discover, create, and attend events. This privacy policy explains how we collect, use, and protect your personal information.

## Data We Collect

### Account Information

| Data Type | Source | Purpose |
|-----------|--------|---------|
| Email address | Registration | Account identification, communication |
| Display name | Registration | Profile display |
| Profile photo | User upload | Profile display |
| Bio/description | User input | Profile display |

### Event Data

| Data Type | Source | Purpose |
|-----------|--------|---------|
| Events you create | User input | Event management |
| Events you attend | User action | Ticket management |
| Posts and comments | User input | Community engagement |
| Event photos/media | User upload | Event content |

### Payment Data

| Data Type | Source | Purpose |
|-----------|--------|---------|
| Wallet balance | System | Virtual currency management |
| Transaction history | System | Payment records |
| Ticket purchases | User action | Ticket management |

### Device Information

| Data Type | Source | Purpose |
|-----------|--------|---------|
| Device type | Browser/Capacitor | App optimization |
| Browser/OS | Browser | Compatibility |
| IP address | Network | Security, geolocation |
| Push token | Device | Notifications |

## Your Rights

### Access

You can request a copy of all data we hold about you. Contact: privacy@eventz.live

### Deletion

You can delete your account at any time:
1. Go to Profile → Settings
2. Click "Delete Account"
3. Confirm deletion

**Note**: Deletion is permanent and removes all your data including:
- Profile and account information
- Events you created
- Posts and comments
- Messages
- Ticket history (transaction records retained for legal requirements)

### Export

You can request an export of your data in a portable format:
1. Contact: privacy@eventz.live
2. We will provide data within 30 days

### Correction

You can update your profile information at any time through the app settings.

## Cookies and Local Storage

### Local Storage

We use `localStorage` for:
- Authentication tokens (session management)
- User preferences (theme, settings)
- Service worker cache

### Cookies

Essential cookies are used for:
- Session management
- Security (CSRF protection)

We do not use tracking cookies or third-party analytics cookies.

## Children's Privacy

Eventz is not intended for users under 13 years of age. We do not knowingly collect personal information from children under 13. If we learn that we have collected personal information from a child under 13, we will delete it immediately.

## Changes to This Policy

We may update this privacy policy from time to time. We will notify you of material changes through:
- In-app notification
- Email to your registered address
- Updated policy posted on our website

## GDPR Compliance

### Data Processing

We process data based on:
- **Contract performance**: Providing the Eventz service

- **Consent**: Push notifications, marketing

### Data Transfers

Your data may be processed in countries outside your own. We ensure adequate protection through:
- Standard Contractual Clauses (Supabase, Vercel)
- Data Processing Agreements with all third parties

### Supervisory Authority

If you are in the EU, you have the right to lodge a complaint with your local data protection authority.
